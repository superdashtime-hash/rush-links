Firebase setup
  1. Create a project at console.firebase.google.com, then add a Realtime Database.
  2. In the database's Rules tab, allow the rooms path (see the README).
  3. Under Project settings → Your apps, add a Web app and copy its firebaseConfig.
  4. Paste it below (saved in this browser), or put it in FIREBASE_CONFIG in index.html so everyone who opens your page can play.
